# Dependency and source notices

PadBridge's own source is Apache-2.0. Source study is not code incorporation.
No code from ATL, Wine, Proton or ACL is copied into this initial implementation.

| Component | Use | License / location of distribution notices |
|---|---|---|
| AOSP aapt, apksigner | Manifest/resource metadata and signature verification, separate Debian processes | Apache-2.0 and component notices, `/usr/share/doc/aapt/copyright`, `/usr/share/doc/apksigner/copyright` |
| Enjarify | DEX to JVM conversion, strict adapter | Apache-2.0, `/usr/share/doc/enjarify/copyright`; original library remains unmodified |
| OpenJDK 21 | JVM and class library | GPL-2.0 with Classpath exception and bundled notices, `/usr/share/doc/openjdk-21-jre-headless/copyright` |
| SDL2, SDL_ttf, SDL_image | Dynamic graphics/input libraries | zlib and bundled dependency notices, respective Debian copyright files |
| bubblewrap | Mandatory process sandbox | LGPL-2.0-or-later, Debian copyright file |
| smali | Build-only fixture assembler | BSD-3-Clause and bundled notices, `/usr/share/doc/libsmali-java/copyright` |
| Rust crates | See pinned Cargo.lock | Dependency license inventory generated by `scripts/dependency-licenses.py`; obtain exact source with `cargo fetch --locked` |

Debian ISO redistribution includes its package copyright files. Sources and
license texts for Debian packages are available from Debian source repositories;
when distributing modified dependencies, publish the corresponding modified
source and satisfy the applicable license. No proprietary Google/Netflix APK,
DRM module, signing key, certificate or Google Play binary is in this repository.

## Added in 0.2

- Xerial SQLite JDBC and SQLite, supplied by Debian: see
  `/usr/share/doc/libxerial-sqlite-jdbc-java/copyright` and SQLite notices.
- FFmpeg, supplied unmodified by Debian: LGPL/GPL components and enabled build
  options retain `/usr/share/doc/ffmpeg/copyright` and `ffmpeg -L` notices.
- Test-only R8/D8 8.3.37: BSD-style upstream license,
  https://r8.googlesource.com/r8/+/refs/heads/main/LICENSE . The pinned download
  checksum and Google Maven URL are in `scripts/fetch-test-tools.py`.
- Test-only Android API stubs 4.1.1.4: published Google Android Maven artifact;
  upstream Android component licenses. Not included in runtime or ISO.
- Test-only Kotlin 1.3.31 compiler/stdlib: Debian package, Apache-2.0 and component
  notices in `/usr/share/doc/kotlin/copyright`. Its bytecode is only in private
  generated test APKs, not the distributed demo or source repository.
- TV Bro and Launch on Boot were obtained from upstream GitHub release assets
  for local compatibility testing. They are not redistributed or bundled. Their
  URLs, versions and APK SHA-256 values are retained in the compatibility record.

## Added in 0.4

- FFmpeg libavformat/libavcodec/libavutil/libswscale/libswresample dynamically
  linked from Debian 13. Debian build options and LGPL/GPL component notices
  apply; package copyright/source information is retained in the ISO. This is
  not a new FFmpeg implementation or a claim that all enabled codecs are tested.
- Mesa EGL/GLES libraries: MIT and component notices in Debian packages.
- Chromium WebView subprocess: Chromium BSD-style and bundled third-party
  notices in `/usr/share/doc/chromium/copyright`; no sandbox-disabling patches.
- ASM 9.8: BSD-3-Clause, `/usr/share/doc/libasm-java/copyright`. Used only to adapt
  derived JVM constructor bytecode; the original signed APK is untouched.
- Official Google Android API 35 SDK stubs: test compilation only. Pinned archive
  and jar digests are in `scripts/fetch-test-tools.py`; never shipped in the ISO.
- Jellyfin Android TV 0.20.1: original official upstream release used privately
  for compatibility analysis; not redistributed in PadTV's repositories/ISO.
- Original Enjarify package remains unmodified on disk. `runtime/dex_fixes.py`
  applies a documented general exception-handler adapter at translation time.
